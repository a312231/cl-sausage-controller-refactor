# 测试图像说明

为了使烤肠检测功能正常工作，请在此目录下添加以下测试图像文件：

1. `test_image.jpg` - 用于烤肠检测的测试图像

您可以从项目的 `python/detect/final/new_test/` 目录中复制任意一张图像（如 `1.jpg`），并将其重命名为 `test_image.jpg` 放置在此目录中。

## 图像要求

- 图像应当包含烤肠或类似物体
- 图像分辨率建议为 832x448 或接近此分辨率
- 图像格式应为 JPG 或 PNG

## 注意事项

在实际应用中，应当从相机实时捕获图像进行处理，而不是使用静态测试图像。本测试图像仅用于演示和调试目的。
